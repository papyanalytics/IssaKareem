# Credit Risk Analysis & Loan Default Assessment
**Onyx Data Challenge | Power BI | Power Query | DAX | ZoomCharts**

### Project Overview
A credit risk analytics project developed for a hypothetical bank as part of the Onyx Data Challenge. The objective was to examine loan default patterns, assess borrower risk characteristics and identify indicators that could support better lending decisions.

### My Contribution
Performed data preparation and analysis, structured the dataset into analytical tables, developed DAX measures and built an interactive Power BI dashboard using ZoomCharts visuals.

### Data Preparation & Modelling
Using Power Query, I:

- Imported the credit risk dataset from Excel and promoted the first row to column headers.
- Assigned appropriate data types to fields, including client IDs, income, age, loan amounts, financial ratios and geographic coordinates.
- Removed rows containing errors and eliminated duplicate records.
- Created separate analytical queries for the cleaned credit risk data, loan facts, client information, loan details and location data.
- Used column selection and removal to retain relevant fields for each analytical table.

This preparation organised borrower, loan and geographic attributes into a more structured reporting model.

### Analysis & Dashboard
Developed seven interactive report sections covering:

- **Portfolio Summary:** Loan volume, default value, default rate and average loan amount.
- **Default Analysis:** Default patterns across borrower and loan characteristics.
- **Risk Analysis:** Relationships between financial indicators and loan defaults.
- **Key Risk Indicators:** Examination of borrower risk characteristics.
- **Risk Breakdown:** Default patterns across different borrower segments.
- **Comparative Risk Analysis:** Comparison of risk across loan categories and borrower groups.
- **Recommendations:** Practical lending and risk management actions.

### Key Insights

- **Default Rate:** 21.8% across the displayed portfolio.
- **Debt-to-Income:** The high DTI group recorded a 74.7% default rate in the displayed analysis.
- **Credit History:** Borrowers with previous defaults recorded a 37.8% default rate, compared with 18.4% for those without previous defaults.
- **Employment Stability:** The 0–2 years employment group recorded a 27.4% default rate, compared with 16.3% for the 10+ years group.

### Business Recommendations

- Apply additional credit assessment checks to borrowers with high debt-to-income ratios.
- Use previous defaults and credit utilisation as indicators for closer monitoring.
- Consider employment stability and repayment capacity during loan assessment.
- Apply risk-based pricing to balance lending returns against default exposure.
